# Travel Expense Reimbursement System

A JavaScript mini project for calculating employee travel expenses and reimbursement amounts.

## Files
- expense.js
- travel.js

## Technologies Used
- JavaScript
- Node.js

## Features
- Travel expense calculation
- Local and outstation travel rates
- Reimbursement limit
- Expense management

## How to Run
1. Install Node.js.
2. Open the project folder in VS Code.
3. Run the JavaScript files using:

   node travel.js
   node expense.js
